# Inova Med

---

## 🎯 Objetivo

O **Inova Med** é um projeto de **site informativo** sobre medicina, desenvolvido para oferecer ao usuário informações básicas sobre temas médicos e de saúde.  
Foi criado com o propósito de aprender e consolidar **noções básicas de HTML** e **CSS**, focando na criação de um layout simples e na organização de conteúdo relevante.

---

## 🛠️ Ferramentas Utilizadas

- **HTML** – Estruturação da página e organização de conteúdo.
- **CSS** – Estilização da página, incluindo cores, fontes, layouts e responsividade.

---

## ✅ Conclusão

Esse projeto foi fundamental para consolidar meus conhecimentos iniciais em **HTML** e **CSS**. Ao desenvolver o site, pude praticar a **estruturação de páginas**, o uso de **tags HTML** e a aplicação de **estilos CSS** para criar uma interface simples e funcional. 

### Aprendizados:
- Como estruturar um site com **HTML**, usando tags e elementos básicos.
- Uso de **CSS** para estilizar e melhorar a apresentação visual da página.
- Como organizar e apresentar conteúdo de forma clara e objetiva.
- Desenvolvimento de uma página **responsiva**, adaptando o layout para diferentes dispositivos.

Este projeto foi uma ótima introdução ao desenvolvimento web, permitindo a aplicação prática dos primeiros conceitos de front-end.
